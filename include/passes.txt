; passes.txt -- record formats of Sea's intermediate files.
; Contract file: changes only together with DESIGN.md section 3 (format of this file: 3.9).
; Comment lines start with a semicolon; empty lines are ignored.
;
; enum <name> <word>...
; head <name> <field>...                  header record, written with a leading number sign
; rec <set> <code> <op> <pops> <field>...
;   set: A sea.ast and sea.res (codes 1-49 both files, 50- sea.res only: 3.4.1);
;        H both HIR files; H1 sea.hir1 only; HF sea.hir only;
;        L both LIR files; LF sea.lir only
;   field: name:type, then optionally ? (the field may be -), then optionally *count
;          (the field is repeated count times, count = an earlier u field): name:type?*count
